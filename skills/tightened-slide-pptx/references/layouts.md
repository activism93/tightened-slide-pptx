Choose one layout before adding objects. Layout ids define narrative structure, not HTML classes.

## Selection Rules

- Use S03 or S09 for a thesis.
- Use S08 for old/new, model/model, or risk/response comparisons.
- Use S11 for linear processes and S14 for repeated loops.
- Use S17 for architecture, validation systems, and technical flows.
- Use S12 or S10 to close.
- Use quantitative layouts only with real data.
- Use S22 only when the large visual is a real image asset, not a rendered slide.

For 7–8 slides, use at least six layout ids. For 10 or more slides, use at least eight.
